DATENSCHUTZ

Lokal statt Cloud

03
⌂

Deine Bilder verlassen diese App nicht automatisch.

Die Bilddateien und Datensätze werden im lokalen Browser-Speicher (IndexedDB) abgelegt. Diese Version enthält keine Upload-Funktion, keine Analyse-API und keine externen Tracking-Dienste.

  • Kein Cloud-UploadEs wird nichts an GitHub oder einen anderen Server gesendet.
  • GerätegebundeniPhone und Pixel haben getrennte lokale Datenbanken. Es gibt keine automatische Synchronisierung.
  • Browserdaten schützenWenn du Website-Daten löschst oder der Browser Speicher freigibt, können lokale Beispiele verloren gehen. Exportiere regelmäßig Sicherungen.
  • Website-VeröffentlichungDer App-Code kann auf einer öffentlichen GitHub-Pages-Adresse sichtbar sein. Das macht deine lokal gespeicherten Bilder nicht öffentlich.
Für vertrauliche Firmendaten nur nach Freigabe durch deinen Arbeitgeber verwenden. Ein lokaler Browser-Speicher ist kein zertifiziertes Archiv und schützt nicht vor Zugriff durch andere Personen mit Zugriff auf dein entsperrtes Gerät.
